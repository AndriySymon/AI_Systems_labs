# C# Code Assistant (Локальна LLM)

## Запуск
1. Встановіть [Ollama](https://ollama.com/) та запустіть сервер.
2. Завантажте модель у термінал: `ollama pull qwen2.5:3b`
3. Встановіть залежність: `pip install openai`
4. Запустіть скрипт: `python main.py`

## 5 Тестових сценаріїв
1. **Базовий запит:** Просимо написати клас `User` на C#.
   *Очікування:* Модель генерує валідний код. *Результат:* Успішно.
2. **Переповнення токенів (Edge Case):** Просимо написати дуже довгий код, який перевищує `max_tokens=600`.
   *Очікування:* Модель обриває генерацію, але програма не падає. *Результат:* Успішно, код обривається, винятків немає.
3. **Обмеження контексту:** Пишемо 8 різних повідомлень поспіль.
   *Очікування:* Застосунок видаляє старі повідомлення, залишаючи лише системний промпт та останні 6. *Результат:* Успішно, контекст не розростається, пам'ять (VRAM) не переповнюється.
4. **Некоректний ввід:** Вводимо порожній рядок або пробіли.
   *Очікування:* Модель просить уточнити запит. *Результат:* Успішно.
5. **Сервер вимкнено (Помилка):** Зупиняємо процес Ollama і запускаємо скрипт.
   *Очікування:* Програма ловить `APIConnectionError` і виводить зрозуміле повідомлення замість стектрейсу. *Результат:* Успішно, виводиться: "[Помилка] Сервер Ollama не запущено".
